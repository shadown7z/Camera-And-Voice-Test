# 摄像头与音视频采集测试工具 - 需求文档

## 1. 项目概述

### 1.1 项目背景
为满足摄像头与音视频采集功能的完整测试需求，开发一款基于 Web 的测试工具，用于检测摄像头、麦克风设备状态及音视频采集质量。

### 1.2 项目目标
- 检测浏览器/系统摄像头、麦克风访问权限
- 识别摄像头设备型号及系统识别状态
- 检测取景画面清晰度、帧率、黑屏、闪屏、镜像、画面颠倒
- 测试麦克风收音及音画同步
- 生成结构化测试报告（支持 JSON/Markdown 导出）

## 2. 功能需求

### 2.1 权限检测模块
- **功能描述**: 检测浏览器是否已获得摄像头和麦克风的访问权限
- **技术实现**: 使用 `navigator.mediaDevices.getUserMedia()` 请求权限，结合 `Permissions API` 获取详细状态
- **输出**: 摄像头/麦克风权限状态（已授权/未授权）、Permissions API 状态

### 2.2 设备检测模块
- **功能描述**: 识别系统中可用的摄像头和麦克风设备
- **技术实现**: 使用 `navigator.mediaDevices.enumerateDevices()` 枚举设备
- **输出**: 设备列表（设备名称、设备ID、分组ID）、设备数量统计

### 2.3 画面测试模块
- **功能描述**: 检测摄像头取景画面质量
- **检测项**:
  - 黑屏检测: 通过 Canvas 分析 60 帧画面亮度，黑帧率 > 80% 判定为黑屏
  - 闪屏检测: 检测帧间亮度突变次数，超过 30% 判定为闪烁
  - 画面颠倒: 比较画面上下半区亮度差异
  - 镜像模式: CSS `scaleX(-1)` 实现镜像显示
  - 分辨率/帧率: 通过 `MediaTrackSettings` 获取
- **输出**: 黑屏状态、闪屏状态、画面颠倒检测、分辨率、亮度百分比、对比度

### 2.4 音频同步测试模块
- **功能描述**: 测试麦克风收音及音画同步
- **技术实现**: 
  - 使用 `AudioContext` + `AnalyserNode` 进行音频频谱分析
  - 实时音频波形可视化（64 条频率柱状图）
  - 3 秒采样周期检测音频信号
- **输出**: 麦克风收音状态、音量等级、音频参数（采样率、声道数）、音画同步状态

### 2.5 测试报告模块
- **功能描述**: 生成结构化的完整测试报告
- **报告内容**:
  - 测试摘要（通过数/总数、错误数、警告数）
  - 设备状态表（权限、设备数量）
  - 画面状态表（黑屏、闪屏、颠倒、分辨率、亮度）
  - 音频状态表（收音、音量、同步）
  - 异常问题点及排查解决步骤
- **导出格式**: JSON、Markdown、剪贴板复制

## 3. 技术方案

### 3.1 技术栈
- **前端**: 纯 HTML5 + CSS3 + JavaScript（无外部依赖）
- **Web API**: 
  - `navigator.mediaDevices.getUserMedia()` - 媒体流获取
  - `navigator.mediaDevices.enumerateDevices()` - 设备枚举
  - `Permissions API` - 权限查询
  - `Canvas API` - 画面帧分析
  - `Web Audio API` - 音频频谱分析
- **UI 框架**: 自定义暗色主题 CSS

### 3.2 架构设计
```
单页应用 (SPA)
├── 进度条组件 (5步流程导航)
├── 权限检测卡片
├── 设备检测卡片
├── 画面测试卡片 (含视频预览)
├── 音频测试卡片 (含波形可视化)
├── 测试报告卡片 (含导出功能)
└── 运行日志面板
```

### 3.3 数据流
```
用户操作 → 权限请求 → 设备枚举 → 视频流获取 → 画面分析 → 音频流获取 → 音频分析 → 报告生成 → 导出
```

## 4. 界面设计

### 4.1 设计风格
- 暗色主题（`#0f172a` 背景）
- 卡片式布局，圆角设计
- 蓝色系主色调（`#38bdf8`）
- 响应式设计，支持移动端

### 4.2 布局结构
- 顶部: 标题 + 5步进度条
- 中部: 5个功能卡片（按步骤排列）
- 底部: 运行日志面板

## 5. 验收标准

### 5.1 功能验收
- [x] 权限检测可正确识别摄像头/麦克风授权状态
- [x] 设备检测可枚举所有音视频输入设备
- [x] 画面测试可检测黑屏、闪屏、颠倒等异常
- [x] 音频测试可检测麦克风收音并显示波形
- [x] 测试报告可正确生成并导出 JSON/Markdown

### 5.2 兼容性验收
- [x] 支持 Chrome、Edge、Firefox 最新版本
- [x] 支持 Windows 10/11 系统
- [x] 支持 HTTPS 或 localhost 环境

## 6. 风险与限制

### 6.1 已知限制
- 需要用户手动授权摄像头/麦克风权限
- 画面颠倒检测为近似算法，可能存在误判
- 音画同步检测为定性评估，非精确延迟测量
- 部分浏览器可能不支持 `Permissions API`

### 6.2 安全考虑
- 所有媒体流在使用后立即释放
- 不存储任何用户音视频数据
- 不向外部发送任何数据
